# 科技人物短视频：运营学习与执行手册

研究日期：2026-10-17（UTC）。适用：科技人物中文解说，抖音与小红书；本手册不执行发布。版本：1.0。

本篇增补既有《人物故事运营复盘》（2026-10-16）。沿用同一最终 SHA-256 的双审核、完整实际听看及发布回读门槛；不降低此前验收要求。人物常驻左下与自然缩窗为本轮具体制作方向，不要求按固定间隔回切全屏人物。封面是否需要区分解说员和故事主角，应按实际构图及必要标识核查，不强制沿用旧版双人物分栏。

## 本轮学习结论

1. 生产验收与增长实验分开：画面无解码错误、音轨完整，不等于人物接续自然，更不等于观众愿意看。技术验收、完整视听审片和发布数据分别留证。
2. “局部修好了”不能替代“整条可用”。开场接续、去除冗余文字等局部变更，都不能自动消除其他口型或人物缺口。
3. 库存按独立、完整、验收通过的内容计数。每日两条，至少未来五天，应有十条独立可用成片；同条双平台复用、旧版本和片段不加数量。
4. 平台 AI 声明与资料署名是发布检查项；自行添加的人物旁常驻文字不是唯一披露方式，也不能将去除冗余装饰文字理解为可删除平台/来源要求的标识。
5. 12:00、18:00 是本项目待验证的固定发布节奏，不是已证明的流量高峰。时区必须先确认，不能把执行机器 UTC 当账号当地时间。
6. 封面短标题与人物面孔、开场主题句、资料镜头密度都应通过受控试验判断；没有真实后台数据，不填写提升比例，不承诺涨粉。

## 证据分层

- **官方指引**：见 `sources.md`，只将可核验官方内容列为依据。检索日不代表指引发布日期，也不代表已查完所有更新。
- **项目制作规范**：本手册中自然接续、常驻左下人物、真实动态素材主体、十条库存是制作与交付标准，不包装成平台推荐算法规律。
- **工程复盘**：从已有制作验收记录抽象得出；本包不包含账号、私密聊天、工作流内部记录或媒体文件。
- **待验证假设**：见“实验计划”。没有填入任何虚构样本或表现数据。

## 一、从选题到可发布成片

### G0：选题成立

每条只回答一个具体问题：人物在什么约束下，做了什么选择，改变了什么？避免仅按出生、学历、职位罗列生平。

交付：主题一句话、观众可获得的解释、关键事实表、至少一个能支撑主题的真实动态素材候选。资料可公开观看不代表可剪辑再发布。素材未清权时，选题仍是候选。

### G1：事实与素材核验

- 每个关键年份、身份、因果、数值和引语记录官方原始出处、事件日期、核验日；观点与事实明确分开。
- 镜头表记录原始素材 URL、权利主体、许可依据、署名要求、原片入出点、片内用途及是否改变原意。
- 历史画面标事件真实日期；后来的采访不能伪装成当年现场。图解写明示意，重建画面不能冒充档案。
- 真实动态素材承担主体叙事；照片、图表仅在解释确有必要时出现，不能靠照片轮播凑时长。
- 不能把资料中真实人物的嘴形处理成在说中文解说，不能捏造原话或克隆人物声音。
- 官方素材库也逐条检查第三方摄影、音乐和肖像条件。NASA 来源不自动意味着所有权利均已解决；参见 S3。

### G2：口播与接续

1. 开场主题句完整说完，按实际音频词尾与自然停顿确定缩窗起点，不为固定秒数截断句子。
2. 优先在同一条连续人物镜头上做缩放/位置变化，平滑落到固定左下区域；不要以另一个重生成镜头替换造成脸型、头向或光线跳变。
3. 接续窗口以正常速度带声音审看，并逐帧检查前后边界：头部位置、视线、眨眼、嘴形、肩部、发丝边缘、曝光、白平衡。
4. 人物尽量常驻；确有缺口时列缺口时间段并退回修复。不能用黑帧、循环假嘴形、长时间冻帧或不相关动作遮掩缺口。
5. 承接前后使用同一锁定旁白版本；禁止靠擅改音轨“修复”局部视觉问题。音轨波形/哈希核查与听审互补。
6. 不用局部预览过关推断整片通过。结尾、所有拼接边界和叠加层变化均单独复查。

### G3：字幕、标识与封面

- 字幕与实际语音逐句核对，重点检查姓名、技术名词、否定词、单位、年份；保留合理断句，避免字数挤压遮挡资料关键画面。
- 左下人物、底部字幕、资料署名各有固定区域，按平台实际预览检查遮挡与裁切，而非假设一套像素边距适用所有界面。
- 资料署名与必要日期保留；署名过长先优化排版/公开正文，不静默删掉权利方要求。
- 不在解说人物旁持续添加冗余“AI生成讲解人物”字样；保留平台 AI 声明以及素材或适用规则要求的显著标识，不去水印/不清除来源元数据以逃避识别。
- 封面突出真实主题人物与短标题。起步设计可试 4–10 个中文字主标题，但这是待测试设计范围，不是平台硬性字数规则。
- 封面兑现内容：不写“震惊”“彻底颠覆”式无证据结论；人物、时代、机构关系准确。商业推广用途须另核肖像和标志条件。
- 各平台分别预览封面裁切、首屏、标题截断；不能把横竖比例转换当成新的内容库存。

### G4：最终验收与唯一版本

必过清单：完整解码；时长与锁定脚本一致；无意外黑帧、静音、冻帧；完整正常速度视听；所有人物接续边界；字幕与资料日期；署名/AI披露；封面预览；事实/许可门槛。

同一最终 SHA-256 须经两位指定审核者独立检查通过，完整实际听看不能由技术指标替代；缺少任一必需审核时维持待审。

每条保存一个 `content_id` 与一个当前批准的 `release_id`。最终导出记录视频 SHA-256、封面 SHA-256、字幕/脚本版本、验收时间与未解决项。任何导出字节变化均重新计算哈希；影响声画/字幕/来源的变更重新审验。文件名含“final”不是通过证据。

版本关系建议：`content_id / release_id / supersedes_release_id / status`。旧版本保留历史标记，不自动删除；上传只从当前批准指针取文件。不同哈希可属于同一内容，哈希相同则绝不是两份库存。

## 二、每日 12:00 / 18:00 库存与排期 SOP

### 时间与时区

排期记录完整日期、IANA 时区、UTC 偏移、计划本地时间与 UTC 时间。时区未确认，状态为 `time_unverified`，不可凭机器日期补排。

示例仅演示换算：若明确采用 Asia/Shanghai，则 2026-10-18 12:00 +08:00 = 2026-10-18 04:00Z，18:00 = 10:00Z。该示例不是已确认排期。

### 每个档位前检查

- 核对平台显示日期、时区依据、当前时间和所选账号；回读排期摘要，防止跨日/过期日期。
- 查已发布、待审核、已排期记录；按 content_id + 平台去重，再比较视频与封面版本，不能因状态尚未刷新重复提交。
- 检查目标档位是否有已验收内容；没有就标缺口并修复，不用候选稿补足数字。
- 声明字段、资料署名、标题、封面和导出版本都核对后，才进入独立授权的发布流程。存在平台限制/警告应停止受限操作，不换路径规避。

### 每次发布后补库存

- 记录实际状态：已提交不等于已发布；排期成功不等于届时一定公开。以平台回执与可见结果确认。
- 每条只有尚未消费的独立成片可贡献未来库存。双平台已用一边、另一边待发，应单独记录平台缺口，不把旧内容重算成完整新一天。
- 以未来五天十个内容档位为覆盖窗口；同条跨平台发布只占一个内容档位。另做平台覆盖检查，任何必发平台受阻都不能声称双平台五天全覆盖。
- `可用库存天数 = 独立验收通过且未消费的成片数 / 2`。十条是本项目底线；每日发布两条后需补回两条，使滚动库存继续保持十条。
- 原型、脚本、素材包、待修片段、旧导出、被新版替代的文件、未清权视频均不计入。

## 三、真实数据复盘

在发布后约 24 小时、72 小时、7 天读取同口径数据；延迟或缺失标 `NA`，不是 0。保存取数时间、作品年龄、平台字段原名、统计口径及是否自然/付费流量。账号级私有数据留在受控台账，Git 仅放空模板与获准的匿名结论。

- 封面：平台确实提供曝光与点击时才算点击率；播放量不能随意替代点击量，信息流自动播放也不等同于主动点击。
- 内容：平均观看时长、完播率、可获得的留存曲线，优先定位明确掉点及其对应镜头。不同视频时长不能只按完播率排高低。
- 价值：收藏、分享、有内容的问题和纠错分别统计；以同一平台实际播放/观看口径作分母。
- 关注：仅在平台明确提供作品归因新增关注时计算；账号粉丝净增不能直接归因于某一条。
- 质量护栏：事实纠错、侵权/误认反馈、标识问题、人物接续投诉、返工时间。增长不能抵消这些失败。
- 对比同平台、相近时长/主题与相同观察窗口，说明节假日、热点和受众差异。小样本只给方向性线索，不宣称因果。

## 四、下一轮实验计划（尚未执行）

首轮建议用十条独立合格成片建立基线；优先保库存与质量，不为实验重复发布同一条。各假设逐轮进行，避免十条同时测所有变量。

### E1 封面短标题是否提升理解与点击

- 变量：一轮只改主标题表达（具体行动 / 具体问题）；人物大小、配色、时长、题材类别尽量固定。
- 发布前先做小屏盲测：能否读清人物和主题，是否误解内容。失败版本不发布。
- 如平台有正式随机分流实验才做同作品 A/B；否则将新作品分成尽量可比的两组，明确标观察研究，题材差异仍是混杂因素。
- 主要指标：平台可提供的封面点击率；次要指标：观看时长、收藏。若无曝光数据，只做可读性结论，不能宣布 CTR 胜出。

### E2 自然接续是否降低转场掉点

- 合格自然接续是底线，不发布黑帧/假口型等劣质版本当对照。
- 可测试范围：两种均自然的停顿/缩窗节奏，保持主题句与固定左下布局。
- 记录接续前后留存（如后台提供足够细粒度）、人工连贯性盲评、制作耗时。没有留存曲线时只报告审片结果。

### E3 12 点与 18 点哪档更适合本系列

- 保持每天两档不变，将相近题材/时长的新内容交错分配到两档；避免全把强选题放同一档。
- 比较相同作品年龄的表现，按工作日/周末分层；首五天只是试运行，不足以确认长期最优时间。
- 不因此自动改既定节奏；有多轮一致证据后再提出调整建议。

### 每轮预先写清

假设、唯一主要变量、主指标、护栏、分组方式、开始/截止日期、样本单位、排除规则、最小有意义提升和分析方法。样本量基于实际基线与可检测差异估算；在没有基线时不编造“统计显著所需条数”。按预定窗口复盘，不因中途好看提前宣布成功。

## 五、下一步与停止条件

- 先验证十条独立成片的清权与全片验收证据，再建立空模板对应的实际受控台账。
- 发布前复核小红书当前官方 AI 公告与实际字段、双方定时发布时区/日期限制；未核验项不得写成已完成。
- 本包只包含可复用方法、官方来源和空白模板；实际媒体、私有后台与账号数据另行保管。
- 不将这份学习手册解释为平台发布、自动运营、账号交互或付费推广的新增授权。
