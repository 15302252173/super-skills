## 执行教程

1. **核对授权账号和当前队列。** 正常打开抖音创作者发布后台，确认当前是内容所有者授权的真实账号。检查已发布、审核中、已定时和草稿，按标题、人物主题、文件与时长核重。特别是曾尝试上传的条目，不能因这份清单写待排就盲目重传。登录或安全验证需按官方流程完成，不绕过。确保仅一个执行者操作上传。
2. **接续队尾。** 重新核对罗曼基线及实际最新队尾、空档、界面时区和可选择的定时日期范围。旧罗曼私密版与任何已有定时条目都不改动。若队尾已变化，保留剩余顺序，整体顺延到队尾之后最近可用的北京时间 12/18 点；如已存在本清单中的作品，跳过它，其他条目重新计算。平台暂不支持远期日期时保留待排，不为绕过限制改成即刻发布。
3. **确认下载版本。** 对照另行提供的私有清单下载准确视频与对应两张封面。校验文件字节数、SHA-256、时长（全部至少 180 秒）；例如在本机用 `sha256sum 文件名` 或 PowerShell `Get-FileHash -Algorithm SHA256 文件名`。不把预览、旧版或同名不同内容上传。不以本次技术校验冒充重新听审；已完成编辑验收的版本不重复生成。出现真实新缺陷，只隔离相应条目修复，不冻结其他合格片。
4. **正常选择文件上传。** 在发布视频页面通过文件选择器选中该视频，等待上传及转码完成；确认视频预览、时长、字幕、完整音轨可正常呈现。不要把“文件选择成功”或“上传 100%”当成“定时已保存”。不要并行操作同一条、反复点击发布或清除正在进行的上传。
5. **填文案与封面。** 逐条复制 PUBLISH_COPY 标题和简介，保留所有资料署名、年份、非原声/非现场说明和示意说明。按界面要求选配 3:4、4:3 封面，预览裁切后人物与文字完整。发布标题、简介、封面、视频画面均不添加链接、二维码或导流联系方式；Git 文档和私有交付位置仅供操作，不可粘到发布文案。若发现素材许可必须保留链接且无法兼容本次无链接要求，停下该条并更换或取得适用授权，不能直接删许可义务。
6. **如实声明 AI。** 在当前发布界面找到 AI 内容声明选项（入口名称可能变化），按实际 AI 旁白、AI 艺术示意情况主动勾选并核实保存。仅在简介写 AI 说明不代替平台声明；不冒充本人原声或历史实拍，不删除原有 AI 标识。
7. **选择定时并逐条提交。** 按重新确认后的日期和界面时区设置定时，复查公开范围、封面、标题、声明与日期。正常提交一次。如出现登录、确认、安全验证或限制提示，遵循提示；不更换账号、不付费、不绕反自动化。
8. **回读确认再处理下一条。** 返回作品管理，确认出现对应条目、正确标题、正确日期时间和定时状态；记录作品标识与回执到私有操作记录。只有此时才把该条标为已排。审核中、上传中、草稿和不确定结果分别记录。提交超时或结果不明先查作品及草稿，未查清不重发。失败先定位一次具体原因，禁止无差别无限重试。
9. **最终交付。** 给内容所有者逐条真实结果：已排/审核中/待排、北京时间、作品回执、具体未解决原因。不要把这张建议表变成虚假的完成表，也不要把私有后台截图或账号数据提交到公开 Git。小红书新增不在本次范围。
