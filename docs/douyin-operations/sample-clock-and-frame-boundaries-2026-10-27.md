# 旁白样本时钟与画面帧边界：避免逐段取整累计

核读与实验：2026-10-27（北京时间；UTC 2026-10-26）。本文为制作工程建议，不是抖音、小红书平台规则或增长结论。补充[制作复盘手册](video-production-operations-review-public.md)的时轴检查，专门给出可执行的整数边界实验，不重复发布去重和时区教程。

## 1. 用累计样本位置定义切点，不反复累加四舍五入秒数

统一无损旁白母带后，以每声道的 sample frame 数 N 与采样率 R 记录长度 N/R；立体声不能把两个声道的标量总数直接除以 R。相邻区间约定为 [start,end)，下段从上一段 end 开始，避免同一个边界样本重复或漏掉。

FFmpeg atrim 的 start_sample/end_sample 按经过滤镜的样本计数，end_sample 对应第一个丢弃样本；它与时间戳选项不同，而且本身不重置时间戳。需要从零开始的片段要明确处理时间戳，不能误以为裁切已经完成。[FFmpeg 官方文档源码：atrim](https://github.com/FFmpeg/FFmpeg/blob/a3f1b1e87c8f485b189f0d68f082342d701eceb0/doc/filters.texi)

建议：先确定母带采样率和实际样本边界，再导出十进制秒给界面。重采样、删句或变速后必须重新建立映射，不能继承旧坐标。样本准确不证明语义完整、接缝自然或声音好听。

## 2. 全局量化画面边界，不让每段独立向上取整

假定输出是从零开始、帧率 F 的恒定帧率网格；F 使用精确有理数，例如 30000/1001，而非将其替换为十进制 29.97。设累计样本位置 S_i，选用一个明确的策略：

`B_i = ceil(S_i × F / R)`，第 i 段分配帧数为 `B_i − B_(i−1)`。

这是“切点不早于音频边界”的设计选择，不是唯一正确剪法。每个量化边界晚于原边界不足一帧，整片只需在总边界量化；相比之下，逐段使用 ceil(N_i×F/R) 再相加，N 段最多多出 N−1 帧。此结论适用于上述数学模型，不直接预言任意编码器输出。

极短的段可能分到零帧。不要强塞至少一帧而重新引入漂移；合并画面段、将标注持续到后续段或重新设计镜头，并检查叙事需要。若不能容忍最多一帧的切点延迟，应明确改用另一策略并评估提前切换的后果。不可通过拉慢或重复旁白配合帧网格。

FFmpeg fps 会按设置复制/丢弃帧，具有独立的时间戳取整与结尾处理选项。因此上述 ceil 模型不是 fps 默认行为的模拟；实际输出必须核帧 PTS、尾帧与边界画面。[官方源码：fps](https://github.com/FFmpeg/FFmpeg/blob/a3f1b1e87c8f485b189f0d68f082342d701eceb0/doc/filters.texi)

## 3. 防止拼接策略悄悄改变旁白时间线

FFmpeg concat **滤镜**按每段最长流推进（末段例外），必要时对较短音频补静音，各段须从零时间戳开始。这与 concat **demuxer**不是同一接口。[官方源码：concat](https://github.com/FFmpeg/FFmpeg/blob/a3f1b1e87c8f485b189f0d68f082342d701eceb0/doc/filters.texi)

制作建议：为连续旁白设计画面时，可先保留连续母带，在全局网格上分配画面，再核对音视频尾部；不是要求把所有已有声画同步素材拆开拼。确需逐段声画共同拼接时，先核每段流长度，明确补静音是否符合编辑意图。不要仅靠最终容器时长一致就放行，也不要无依据用 shortest 截尾。

## 已执行实验：仅合成数值，不含任何真实媒体或账号

运行本目录的 [sample-clock-experiment.py](sample-clock-experiment.py)：

```sh
python3 sample-clock-experiment.py
```

只用 Python 标准库，不读写媒体、不联网、不安装软件。Fraction 接受整数分子分母以保留精确比例；不要先转换浮点再期待恢复原始分数。[Python 官方 fractions 文档](https://docs.python.org/3/library/fractions.html)

Python 3.12.14 实测：

| 合成输入 | 逐段向上取整总帧 | 全局总帧 | 多出帧 |

| 60 段，每段 48001 样本，48000 Hz，30 fps | 1860 | 1801 | 59 |
| 60 段，每段 48000 样本，48000 Hz，25 fps | 1500 | 1500 | 0 |
| 60 段，每段 48000 样本，48000 Hz，30000/1001 fps | 1800 | 1799 | 1 |
| 100 段，每段 1 样本，48000 Hz，30 fps | 100 | 1 | 99 |
| 44099/44100/44101 样本三段，44100 Hz，24 fps | 73 | 72 | 1 |

另执行固定随机种子的 1000 组样本、4 类非法输入、半开区间重建及重复样本故障检查。全部通过：帧数守恒、取整差界限、单边界偏差小于一帧。极短段用例出现 99 个零帧段，说明数学分配不能替代镜头设计。
