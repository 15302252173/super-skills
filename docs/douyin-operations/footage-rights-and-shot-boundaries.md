# 真实动态资料：把许可条件落实到逐镜与逐帧

核读与实验日期：2026-10-27（UTC）。补充[无主持纪录片流程](hostless-documentary-production-workflow.md)第 3—5 节；不重复样本主时钟、归档或平台规则。以下三项为制作改进，不是法律意见或流量承诺。

## 1. 从“网站可用”改成“这个源窗、这个用途可用”

**官方依据。** [DVIDS 版权说明](https://www.dvidshub.net/about/copyright)指出：美国政府雇员履职制作的影像通常在美国不受版权保护，但站内也可能含第三方权利，即使没有版权标记；人物隐私/公开形象权不因此消失，军种标识还可能受商标保护。不能把美国境内的版权结论扩大为全球、全用途授权。页面禁止明示或暗示背书；总则要求非背书声明，非商业段又使用“requested”，措辞不完全一致。制作上保守保留页面当时要求的完整声明；适用范围不清先核实，不自行宣布豁免。商业用途定义还包括推广、募款等，不能只用“账号是否盈利”分类。

**落地改进。** 每个候选源窗分开核五件事：作品本体许可、画中第三方内容、人物/标志、原声/音乐、最终用途和上下文。原片许可不自动覆盖音乐或画中作品；删掉声音也不解决画面权利。核不清则换有明确依据的素材，不以“来源是官方”放行。

[Pexels 许可](https://www.pexels.com/legal-pages/license/)允许免费使用与修改，署名非强制，但限制不当呈现可识别人物、暗示背书及部分再分发等。[Pexels 商业使用帮助](https://help.pexels.com/hc/en-us/articles/360042295214-Can-I-use-the-photos-and-videos-for-a-commercial-project)进一步提醒画中品牌、标志等可能另有权利。模糊标志不能自动取得授权，也不能改坏资料真实性；无法兼顾时直接换镜头。

**待做验证，尚未执行：** 对一个有明确用途的真实候选片段填完上述五栏，保留逐项证据或“未知”；未知项不得用总许可勾选代填。核完不等于已经取得所有必要授权，更不等于该片已发布。

## 2. 把“无 URL”拆成呈现位置，而不是删掉许可义务

**官方依据。** [CC BY 4.0 官方摘要](https://creativecommons.org/licenses/by/4.0/)要求适当署名、许可链接与改动说明；并不保证肖像等所有必要权利。[法律正文第 3 节](https://creativecommons.org/licenses/by/4.0/legalcode.en)允许结合媒介、方式与语境合理履行，包括链接到包含必要信息的资源。法律正文也允许提供许可证全文，而非只能给许可 URL；仍须满足其余适用条件。不是所有场景都必须把长网址烧进画面，也不是只写作者名就够。

**落地改进。** 素材确定前先填下面的呈现矩阵，不等成片后再删字：

| 检查项 | 处理方法 |
|---|---|
| 仅封面/片内不显示 URL | 检查发布说明等实际可用位置能否合理承载完整必要信息；不能凭模板假定合规 |
| 所有公开位置都不允许 URL | 先核许可证是否允许完整文本等替代及能否合理呈现；仍不兼容则换素材或取得另行许可，不用私有台账替代公众署名 |
| 非背书声明、资料年份、改动说明 | 与署名和平台 AI 声明分别列出；不因“清爽画面”一起删除 |
| Pexels 不强制署名 | 不自动豁免人物、品牌与上下文检查，也不能套用于其他素材库 |

**待做验证，尚未执行：** 用三个虚构审查卡走查：必须链接且无合规替代、无公开位置 → 不放行；仅画面禁 URL 且另有合理完整呈现 → 待核该具体呈现；署名非强制但暗示品牌支持 → 不能因免署名放行。该走查检查流程分流，不自动判定真实权利。

## 3. 将批准源窗写成半开区间，并检查最终边界污染

**官方依据。** [FFmpeg trim](https://ffmpeg.org/ffmpeg-filters.html#trim)的 `start_frame` 是首个保留帧，`end_frame` 是首个丢弃帧；帧选项按经过滤镜的帧计数，时间选项看时间戳。`trim` 不重置时间戳，必要时接 `setpts=PTS-STARTPTS`。不要把 `end_frame` 当作最后保留帧。

**落地改进。** 镜头卡同时保留：源版本、解码帧序号 `[a,b)`、源 PTS/时基、输出区间、变速/裁切/转场、原字幕或标识出现区间，以及必要标签/署名位置。帧序号必须绑定同一解码链；先 seek、fps 或插帧后，原帧号未必仍有效。可变帧率不能简单用帧号除以名义 fps 充当准确时间。原字幕需判断其语义与权利，不能一概当水印抹掉。

硬切至少加查切点前一帧、切点帧和后一帧；叠化逐帧检查整个重叠区。用于转场的额外头尾帧也必须属于已核准源窗，不能把剪辑软件的 handles 当成额外授权。必要资料标签应覆盖该资料实际可见的区间，不在转场开始时过早消失。边界加查之外，仍完整检查实际采用的源窗和最终输出。

### 已执行的离线合成实验

运行 [footage-boundary-experiment.py](footage-boundary-experiment.py)：

```sh
python3 footage-boundary-experiment.py
```

需要已安装的 Python 与 FFmpeg；不联网、不安装软件，不下载真实素材。脚本在临时目录创建 60 帧灰度合成输入，各帧像素值对应零起始序号，用 FFV1 无损编码再由 FFmpeg 解码裁切。退出后清理临时媒体。

2026-10-27 实测环境：Python 3.12.14，FFmpeg 7.1.5-0+deb13u1。

| 用例 | 实测结果 |
|---|---|
| `[15,45)` | 30 帧，首帧值 15、末帧值 44；所有像素与预期一致 |
| 故意误写 `end_frame=46` | 31 帧，混入源帧 45；长度/内容比较拒绝 |
| 输出第 14 帧注入 4 像素角标 | 检查第 0、15、29 帧均未发现；全帧比较仅定位第 14 帧 |
| 相邻 `[15,45)` 与 `[45,60)` | 合并严格等于源 `[15,60)`；边界未重漏 |

这是已运行的机械回归测试。角标污染在解码数组中人为注入，不是实际字幕渲染、品牌识别或 OCR 测试；灰度序号不是自然动态影像。它验证半开区间与稀疏抽样的漏检实例，**不证明**真实素材许可已通过、自然画面内容正确、转场/字幕可读、平台转码正常或观看效果改善。有损编码不宜直接套逐像素相等，应另设可解释的测量与人工检查；本次未做音频、实际听审、平台上传或自然视频测试。

**下一步真实镜头验证，尚未执行：** 固定一个已取得适用权利的短源窗及剪辑参数，导出后核全部实际可见源帧和切点，记录原字幕/标识是否越界、转场是否越过批准源窗、标签是否覆盖完整。停止条件是预定区间与全部边界均得到结果，或权限/检查能力不足时如实留未验证；不为得到通过反复换样本。
